## Setup and use

- Install dependencies with `.venv/bin/python -m pip install -r requirements.txt`. PyTorch is already installed in this workspace's virtual environment.
- Run tests with `PATH="$PWD/.venv/bin:$PATH" make test` from the repository root.
- Supply CPU float32 tensors to the backend. Create training with `model.cdk_fun(None, None, k=1)` and call the result with `(batch, masks)`. Call `model.predict()(batch)` to obtain probability tensors.
- Sampling uses a private generator seeded with 17. Set `np.random.seed(...)` before construction if repeatable initial weights are needed.
