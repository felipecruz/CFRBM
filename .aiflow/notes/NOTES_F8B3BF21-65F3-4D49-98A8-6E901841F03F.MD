# F4 reference usage

- Import the deterministic oracle from `tests.rbm_reference`. Supply fixed binary samples to `sample_visible`; it returns the supplied samples and normalized sigmoid probabilities.
- `parameter_update` returns `(weights, vbias, hbias, prev_gw, prev_gv, prev_gh)` as new float32 arrays. Its gradient input uses `(gw, gv, gh)` ordering.
- Run the checks from the repository root with `PATH="$PWD/.venv/bin:$PATH" make test`. All 9 tests passed on Python 3.12.2.

## Follow-up

Use this reference in F5's backend parity harness. It intentionally retains the F10–F12 quirks; it does not validate random-number streams or live Theano execution.
