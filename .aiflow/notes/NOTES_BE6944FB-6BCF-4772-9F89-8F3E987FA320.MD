# Run training

From the repository root, run `make run PYTHON=.venv/bin/python` or activate `.venv` and run `make run`. Use `DEVICE=cpu` to force CPU. Both configured MovieLens split files were extracted from the existing local archive and remain untracked in `ml-100k/`. Follow README.md for setup on another machine.

# Validation and follow-up

The default command completed epoch 0 on CPU (MAE 0.931794, RMSE 1.187261) and wrote results before it was intentionally stopped. This is a startup check, not the F9 accuracy baseline. Run all 100 epochs for F9. Each run overwrites its named results JSON. The startup-check results and log are saved locally at `/tmp/cfrbm-f8-first-epoch.json` and `/tmp/cfrbm-f8-make-run.log`.

27 tests passed; 2 accelerator tests were skipped because CUDA and MPS were unavailable in this sandbox. Both CLI integrations and all eight math parity checks passed.
